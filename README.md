# MetroRent UK: London Rental Affordability Analysis

## 📌 The Business Problem
MetroRent UK, a fictional proptech platform expanding across London, needed to identify high-growth and affordable boroughs for property acquisition. The goal was to clean a messy VOA dataset and visualise rent trends for 2-bedroom properties across Greater London.

## 🛠️ Tools Used
- **Excel:** Data cleaning, filtering out non-borough aggregates (E12/E13), and removing missing values.
- **SQL (SQLite):** Querying the database to extract top expensive/affordable boroughs and average rents.
- **Power BI:** Building an interactive dashboard to visualise rental trends over time.

## 🔍 Key Findings & Recommendations
1. **Most Expensive:** Kensington and Chelsea has the highest average rent for a 2-bed at roughly £2,600.
2. **Most Affordable:** Bexley offers the most affordable 2-bed rent at roughly £1,300.
3. **Recommendation:** MetroRent UK should prioritise expansion in mid-tier boroughs like Barking and Dagenham or Havering, as they offer a balance of affordability and market accessibility.

The VOA data is non-statistical and should not be used for precise time-series comparisons. The analysis focused on 2-bedroom properties to ensure a like-for-like comparison across boroughs.
